Tester steps · Round 1 (v0.1.15, Oct 31 2026)

Pre-alpha. Android only. Do these in order. Only the apps in this round are listed here; everything else under Apps is for later rounds.

①

Omni Node (the daemon)

Uninstall any older Omni Node first. Install, open it and turn the Network switch on. Allow notifications and "keep running in background". The status card should go green or teal ("Connected to N nearby" / "Looking for nearby people..."). Then tap Connect apps, unlock, and Copy token. If the card turns red or the switch won't stay on, report it (step 5).

Download Omni Node
②

KickBack Social

Install and accept the tester consent screen. Open Hub settings (gear), choose Remote hub, type 127.0.0.1 and paste the token from step 1. Then make a post and react to one. Use the in-app Bug report button for anything odd.

Download KickBack
③

OmniCast (look only)

Open it and look around Classroom Mode. Video calls are not working yet; tell us what you think of the screens.

Download OmniCast
④

Omni Hub (preview of the final look)

Last step. If the Omniverse Superapp is installed, uninstall it first (they share an app ID). This shows where everything is heading.

Download Omni Hub
⑤

Report a problem

Say which app and step, what you expected, what happened, and your phone model and Android version. A screenshot helps.

Open a report

Android may warn about installing from your browser: allow "Install unknown apps" for it, then install.
